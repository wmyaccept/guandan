# 从买机器到公网能打开

目标：买一台腾讯云轻量应用服务器（Ubuntu 24.04），把本机 `D:\work\guandan` 放到云上，朋友用手机流量也能打开打牌。

这台机器在腾讯的机房里，不是寄到你家的电脑。你的 Windows 只负责买、登录、把代码传上去。

## 1. 注册并实名

1. 打开 [腾讯云](https://cloud.tencent.com/)。
2. 登录。没有账号就注册，用微信或手机号都可以。
3. 按提示完成个人实名。不实名买不了机器。

新用户常有轻量机首购优惠，买一个月先练手即可。

## 2. 买轻量应用服务器

1. 打开 [轻量应用服务器购买页](https://buy.cloud.tencent.com/lighthouse)。
2. 地域选 **上海** 或 **广州**，离你和朋友近。
3. 镜像一定选 **系统镜像**，操作系统选 **Ubuntu 24.04**。不要选 WordPress、宝塔、Node.js 应用镜像。
4. 套餐选 **2核 2GB** 或 **1核 2GB**，流量 200GB 以上。四个人打牌足够。
5. 时长先选 **1个月**。
6. 下单付款。

几分钟后，控制台 [轻量应用服务器列表](https://console.cloud.tencent.com/lighthouse/instance) 里会出现一台机器，状态是「运行中」，并显示 **公网 IP**，例如 `119.45.x.x`。把这个 IP 记下来。

## 3. 设登录密码

1. 点进这台机器。
2. 找到 **重置密码**。
3. 设一个你记得住的 Linux 密码，等机器重启完成。

之后登录用户名是 `ubuntu`，密码就是刚设的。

## 4. 放行网站端口

在这台机器页面打开 **防火墙**：

- `22` SSH（一般已有）
- `80` HTTP
- `443` HTTPS

没有就「添加规则」。`3000` 不用对公网开放。

## 5. 用浏览器登录机器

在实例页面点 **登录**，选网页终端。用户名 `ubuntu`，输入刚才的密码。

看到类似下面这就对了：

```text
ubuntu@VM-0-4-ubuntu:~$
```

后面标了「在云服务器里执行」的命令，都粘到这个黑窗口，回车。

## 6. 安装 Node.js 和 Nginx

在云服务器里执行：

```bash
sudo apt update
sudo apt install -y nginx
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
node -v
nginx -v
```

`node -v` 应看到 `v22` 开头。

## 7. 把代码从 Windows 传到云上

在 **Windows 的 PowerShell** 里执行（把 IP 换成你的公网 IP）：

```powershell
scp -r D:\work\guandan ubuntu@你的公网IP:~/guandan
```

第一次会问 `Are you sure you want to continue connecting`，输入 `yes`。然后输入 ubuntu 密码，输入时屏幕不显示，输完回车。

传完后，回到云服务器网页终端：

```bash
ls ~/guandan
```

能看到 `package.json`、`server`、`public`、`deploy` 即可。

如果 `scp` 报错，可安装 [WinSCP](https://winscp.net/)，协议 SFTP，主机名填公网 IP，用户名 `ubuntu`，密码同上，把 `D:\work\guandan` 整个拖到右侧 `/home/ubuntu/guandan`。不要传 `node_modules` 也没关系，下一步会重新安装。

## 8. 安装依赖并试跑

云服务器里：

```bash
cd ~/guandan
rm -rf node_modules
npm install --omit=dev
PORT=3000 HOST=0.0.0.0 node server/index.js
```

看到 `掼蛋桌已开` 就对了。先 `Ctrl+C` 停掉，再交给系统托管，否则你一关终端程序就没了。

## 9. 设为开机自启

云服务器里：

```bash
sudo cp ~/guandan/deploy/guandan.service /etc/systemd/system/guandan.service
sudo systemctl daemon-reload
sudo systemctl enable --now guandan
sudo systemctl status guandan
```

看到 `active (running)` 就是成功。以后重启机器也会自动开桌。

## 10. 用 80 端口对外

云服务器里：

```bash
sudo cp ~/guandan/deploy/nginx.conf /etc/nginx/sites-available/guandan
sudo ln -sf /etc/nginx/sites-available/guandan /etc/nginx/sites-enabled/guandan
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx
```

手机关掉 Wi-Fi，用流量打开：

```text
http://你的公网IP
```

能看到掼蛋开桌页面，就可以把这个地址发给朋友。

## 11. 可选：域名和 HTTPS

没有域名也可以一直用 `http://公网IP`。有域名的话：

1. 域名解析一条 A 记录到这台机器的公网 IP。
2. 把 `~/guandan/deploy/nginx.conf` 里的 `server_name _;` 改成你的域名。
3. 再执行：

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名
```

之后用 `https://你的域名` 打开。

## 以后改代码

Windows 再传一次，然后云上执行：

```bash
cd ~/guandan
rm -rf node_modules
npm install --omit=dev
sudo systemctl restart guandan
```

## 卡住时看这里

- 网页打不开：防火墙有没有 80，Nginx 是否 `active`。
- 能打开页面但进房立刻掉线：Nginx 没加 WebSocket 的 `Upgrade` 头，确认用的是仓库里的 `deploy/nginx.conf`。
- 关了网页终端游戏没了：没有执行第 9 步的 `enable --now guandan`。
- 看日志：`sudo journalctl -u guandan -n 50 --no-pager`
